# 端末操作と接続維持

## 選択・リンク・表示

端末下部のテキスト選択ボタンを押し、ダブルタップまたは長押し →「選択」で文字を選ぶ。選択ハンドルをドラッグして範囲を広げ、端末下部か選択メニューのコピーボタンを使う。この間は tmux などへのマウス報告とウィンドウ切り替えスワイプを止める。終了ボタンで端末の操作に戻る。

OSC 8 と画面に表示された HTTP(S) URL はタップで開ける。タップしたセルから前後の表示行を調べ、VT のソフトラップと、screen/tmux の再描画でセルが行末まで埋まる折り返しをつなぐ。折り返された先の行もタップできる。行が画面外にある場合は URL 全体を表示する位置までスクロールする。URL 以外のコピーでは端末の改行を保つ。

文字サイズは「設定 → 表示」で 6〜32pt。ピンチと物理キーボードの文字サイズ操作も同じ範囲を使う。

## tmux / screen のキー列

SSH 接続中に入力補助バーの「キー」を押すと、登録したキー列が出る。「コピー (^A)」は Ctrl+A、Esc を順に送る。GNU screen のコピーモードと、Ctrl+A が prefix で Escape を copy-mode に割り当てた tmux で使える。標準の tmux では「コピー (^B)」が Ctrl+B、`[` を送る。コピーモード中の操作は接続先のキーバインドに従う。キー列モードには Esc と矢印キーを置いている。

「設定 → キー列」で最大12件を登録できる。キーは空白で区切る。例は `^A ^[`、`^B [`、`M-x`、`Escape`、`Tab`、`Space`、`Enter`、`Up`、`PageUp`、`F1`。ボタンを押したときに、キー列のバイトを一つの順序付き入力として送る。Enter を入れたキー列は改行を送る。

日本語フリックの右下は改行・確定、キーボードを閉じる操作は端末下部へ。英数・記号などの非フリック配列は押下中にキー名を上に表示する。

## SSH 接続維持

15秒ごとに SSH の `keepalive@openssh.com` を送り、応答は最大90秒待つ。サーバーがその種類の要求を拒否しても、SSH の拒否応答が届けば通信は生きている。サーバーでコマンドを実行せず、PTY の出力・入力順序にも影響しない。サーバーのシェルが終了した場合は終了として表示し、通信断の場合は自動再接続の設定に従って同じタブで再試行する。

iOS がバックグラウンド実行時間を使い切った場合は、OS に実行枠を返す。アプリはそこで SSH を明示切断せず、OS やネットワークが接続を閉じた場合に復帰後の再接続を行う。再接続で新しい PTY が開く。tmux に残した作業には、接続先で `tmux attach` して戻れる。「設定 → 画面を自動ロックしない」で、前面利用中の自動ロックを抑えられる。
